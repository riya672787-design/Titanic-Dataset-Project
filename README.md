# Titanic Dataset Machine Learning Project

## 📌 Project Overview

This project analyzes the Titanic dataset using Python and Machine Learning.

The main objective is to analyze passenger information and predict whether a passenger survived the Titanic disaster.

## 🎯 Objectives

- Analyze the Titanic dataset
- Clean and preprocess the data
- Perform Exploratory Data Analysis (EDA)
- Visualize important patterns
- Train Machine Learning models
- Evaluate model performance
- Predict passenger survival

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- GitHub

## 📊 Dataset

The dataset contains information about Titanic passengers such as:

- Passenger Class
- Sex
- Age
- Siblings/Spouses
- Parents/Children
- Fare
- Embarked
- Survival

### Target Variable

`Survived`

- 0 = Did not survive
- 1 = Survived

## 🔄 Project Workflow

1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Exploratory Data Analysis
5. Data Visualization
6. Feature Selection
7. Model Training
8. Model Evaluation
9. Survival Prediction

## 🤖 Machine Learning

This project treats Titanic survival prediction as a binary classification problem.

The model predicts whether a passenger:

- Survived
- Did not survive
